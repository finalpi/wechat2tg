# WeChat emoji assets

The active WebP assets are copied unchanged from [finalpi/wechat-emoji](https://github.com/finalpi/wechat-emoji) at commit `f4a96e4a1ee173afc8d1ddfc55d604777bb37890`. 109 files are 128×128 transparent WebP from [Nimbly8836/wechat_rails](https://github.com/Nimbly8836/wechat_rails) at commit `9eaac826504a3d4d67ead8c05b737a69ca64a3e9`. `加油加油.webp` is a lossless conversion of the existing 64×64 PNG, preserving the original artwork.

Original WeChat artwork is credited to its rights holders. These source records do not assert a new image license. `manifest.json` records filenames, hashes and dimensions.

The old PNG snapshot (`01f1039f296ec166c29edf195c739a179577bc6c`) is retained for compatibility with previously opened pages; active links and the display manifest use WebP. Chinese and English aliases are retained, including `[發]` and `[爆竹]`, which now have WebP artwork. Telegram conversion settings remain separate from Web display.
