# Telegram 查看朋友圈与本地归档

## 查看联系人

微信已登录后，Bot 主人在 **已绑定单个微信联系人的 Telegram 聊天或话题**里直接发送 `/moments`，**无需参数，也没有联系人选择菜单**。Bot 只读取该联系人，并在当前聊天或话题显示内容，不另发私聊。发到群里的内容对群成员可见；只有 Bot 主人可以发起读取或点击翻页等按钮。

绑定的是微信群、公众号或未绑定时不会读取。点「下一条」浏览已获取的动态，点「加载更多」向微信请求下一页。

动态展示作者、发布时间（UTC）、正文、图片、赞数和评论数。默认优先发送 Telegram 原生富文本，把正文和图片合成一条消息；显式设置兼容模式，或 Telegram 明确拒绝后，才使用 HTML 和普通相册。第一版不展开评论内容、不预览视频或特殊附件，也不支持点赞或评论。图片不可用时仍显示正文。

读取使用 `/FriendCircle/GetDetail`。首次发送 `Maxid: 0`，分页用 XML 中的精确 64 位动态 ID 作为游标，不把 ID 转成 JavaScript 的普通数字。保留微信返回的「朋友仅展示最近三天的朋友圈」等提示。没有可见内容时明确显示空态，不把它当作接口或 Telegram 发送失败。不会尝试访问超出当前可见范围的内容；上游没有返回更多时停止。

## 按联系人单独保存

1. **一次性保存**：在同一绑定聊天或话题里直接发 `/savemoments`。也可以点「保存设置」→「立即保存当前可见的全部动态」。Bot 会逐页读取微信当前可见的内容并在当前会话报告结果，不会开启每日同步。单次最多处理 200 页或 15 分钟，达到时可在结果页点「继续保存」。
2. **每日同步**：在该联系人的「保存设置」点「开启每日同步」。默认关闭，只同步你单独开启的人；每人至少间隔 24 小时，间隔跨重启保留。Bot 和微信在线时会检查到期的联系人，增量同步遇到整页已归档内容即停止；手动保存则会继续翻页。同步不把朋友圈批量发送到 Telegram。手动浏览时，已开启同步的人也会就地归档。
3. **查看归档**：用「查看本地归档」打开。归档保存正文和成功下载的图片副本（压缩），不只保留链接。相同动态按 ID 去重，切换微信账号后不会显示原账号的归档。关闭每日同步不删除旧记录；「清空此人归档」需另行确认，不影响微信原帖，也不会撤回已发送到 Telegram 的消息。

归档保存在 `storage/db/moments.db`，全库最多 2,000 条，正文和图片载荷合计限制为 128 MiB；达到上限不自动删除旧内容，仍可查看线上动态。主动查看时内容会发到当前 Telegram 聊天，并请求 Telegram 限制转发和保存；显示在群里的内容并非仅主人可见，也并非只存在本机。请按需要开启，并保护存储目录和备份。
