# Telegram 查看朋友圈与本地归档

## 查看联系人

微信已登录后，Bot 主人可直接发送 `/moments`，**无需参数**：

- 在绑定单个微信联系人的 Telegram 群或话题里，自动选中这个人；内容只发给 Bot 主人的私聊，群里仅提示去私聊查看。
- 在 Bot 私聊里，直接点选联系人并可翻页，也可通过「归档联系人」看已保存的人。`/moments 昵称或备注` 是可选的搜索快捷方式，不是必填项。

别人的 Telegram 账号不能读取朋友圈；绑定的是微信群、公众号或未绑定的会话时，请从私聊选择个人联系人。点「下一条」浏览已获取的动态，点「加载更多」向微信请求下一页。

动态展示作者、发布时间（UTC）、正文、图片、赞数和评论数。Telegram 的展示模式允许原生富文本时，正文和图片合成一条富文本消息；明确不支持时回退到 HTML 图文和普通相册。第一版不展开评论内容、不预览视频或特殊附件，也不支持点赞或评论。图片不可用时仍显示正文。

读取使用 `/FriendCircle/GetDetail`。首次发送 `Maxid: 0`，分页用 XML 中的精确 64 位动态 ID 作为游标，不把 ID 转成 JavaScript 的普通数字。保留微信返回的「朋友仅展示最近三天的朋友圈」等提示。不会尝试访问超出当前可见范围的内容；上游没有返回更多时停止。

## 按联系人单独保存

1. **一次性保存**：直接发 `/savemoments`。绑定联系人的群或话题会自动选中这个人；私聊中点选联系人即可。也可以在该联系人的「保存设置」点「立即保存当前可见的全部动态」。Bot 会逐页读取微信当前可见的内容并在私聊报告结果，不会开启每日同步。单次最多处理 200 页或 15 分钟，达到时可在结果页点「继续保存」。
2. **每日同步**：在该联系人的「保存设置」点「开启每日同步」。默认关闭，只同步你单独开启的人；每人至少间隔 24 小时，间隔跨重启保留。Bot 和微信在线时会检查到期的联系人，增量同步遇到整页已归档内容即停止；手动保存则会继续翻页。同步不把朋友圈批量发送到 Telegram。手动浏览时，已开启同步的人也会就地归档。
3. **查看归档**：用「查看本地归档」打开。归档保存正文和成功下载的图片副本（压缩），不只保留链接。相同动态按 ID 去重，切换微信账号后不会显示原账号的归档。关闭每日同步不删除旧记录；「清空此人归档」需另行确认，不影响微信原帖，也不会撤回已发送到 Telegram 的消息。

归档保存在 `storage/db/moments.db`，全库最多 2,000 条，正文和图片载荷合计限制为 128 MiB；达到上限不自动删除旧内容，仍可查看线上动态。内容会发送至 Telegram 私聊，并请求 Telegram 限制转发和保存，但并非只存在本机。请按需要开启，并保护存储目录和备份。
