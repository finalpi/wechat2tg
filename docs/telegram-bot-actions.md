# Telegram Bot：收藏表情、接收转账与默认头像

## 收藏微信表情

先私聊 Bot 并点击「开始」。在绑定的 Telegram 聊天中，回复一条图片、GIF 或视频贴纸发送 `收藏`（也可用 `/collect`），或者给 Bot 转发的媒体消息点 👍。回复指令不会转发到微信；只有配置的 Bot 主人能收藏。群里通过 👍 触发需要 Bot 是管理员、该聊天允许 👍，且 Bot 能收到个人反应更新。带文字说明的 GIF（包括 Telegram 以 MP4 存储的动图）也可以收藏。旧消息没有媒体索引时，👍 会尝试用已登录的 Bot MTProto 会话读取原消息。仅处理已授权聊天或话题里的 Bot 或主人发送的媒体。如果 Bot 无法读取旧消息，请回复原消息发送 `/collect`；能从回复中读取媒体时，Bot 会补建索引。

首次成功时打开 Bot 返回的链接添加「微信收藏 01」。以后可直接从 Telegram 的贴纸面板发送；在绑定聊天发送的贴纸沿用现有转发到微信的流程。每包最多 120 张，满包后自动新建下一包；按媒体内容去重。动图最多保留前 3 秒，可能压缩；不支持 TGS 矢量动画，无法转换的文件不上传。**贴纸包不是私密存储，知道链接的人可能访问，请勿收藏私密图片。**

## 接收微信转账（实验性）

满足收款人、发送者、有效期和协议标识校验的**新单聊转入**，转发到绑定 Telegram 聊天时会附带「接收转账 ¥…」按钮。只有 Bot 主人能点击，点击即授权向当前微信账号尝试收款。群聊、自己转出、过期或缺少可靠信息的消息仅提示，不提供收款按钮。没有自动接收、付款、退款或 WebUI 收款入口。

接收使用 v6 协议的 `/TenPay/Collectmoney`。Bot 先记录操作，再发一次请求；不因超时、重启或 Telegram 界面更新失败重试。协议仅返回外层成功，不代表到账。若收到同账号、同会话、同笔交易的原生收款回执，下次点击状态按钮会显示「已收款」；否则请在微信确认。当前以合成消息和本地模拟接口验证，未进行真实资金操作。

## 默认 Bot 头像

Bot 连接 Telegram 后会检查自身头像。只有确认没有头像时，才上传随程序打包的绿色双聊天气泡头像；不会在线下载头像原图、取用你的微信头像、修改群组头像或覆盖 Bot 的已有头像。检查或上传失败不会阻止 Bot 启动。使用不支持 `setMyProfilePhoto` 的旧版自建 Bot API 时，可在 BotFather 手动设置。
