# 聊天界面与显示偏好

入口：聊天菜单 → 管理设置 → 聊天界面。

- 在通讯录预览中点击眼睛，隐藏或恢复群聊、公众号、服务号、企业微信联系人、联系人、待识别分类。
- 偏好即时生效于聊天列表和通讯录，保存在当前浏览器的 `webui-chat-preferences-v1` 中；不跨设备同步，不修改实例的转发规则，不删除任何消息或联系人。
- 「显示全部分类」恢复默认显示。隐藏正在打开的会话会返回列表，但保留其未发送草稿。拖动排序尚未实现。
- 鼠标悬停消息或键盘聚焦操作时显示回复、同步、撤回等工具；触屏通过每条消息旁的省略号打开。发送失败、结果未知和撤回结果仍会直接提示，不隐藏重要错误。
- 连接状态默认仅显示 emoji；点击可查看微信、Telegram 和消息连接详情。未接入的「新的朋友」「我的企业」不再占用通讯录空间。

## 头像

群消息中的每位发言人（含自己）、成员选择器都显示头像。优先使用联系人缓存；非好友的头像可以从所属群的成员资料中取得。缺失或加载失败时显示名字首字占位，不伪造头像。

Web 头像仍经鉴权接口获取，仅允许微信头像 CDN；同一页面中的重复头像请求合并，退出/更换登录会话时释放缓存，不将头像写入浏览器持久存储。

Telegram `/members` 的富文本分页在当前页加入成员头像图集。头像编号与原有成员列表一一对应，图片说明中的编号也可以打开该成员详情。只使用合法的微信头像 CDN URL，不加载隐藏分页的图片；头像缺失时保留姓名列表。明确的富文本不支持或头像拒绝响应会退回文字列表与原有按钮；网络超时等结果不明的错误不会自动重复发送。真实显示效果取决于 Telegram 客户端及 Bot API 的富文本支持。

## 验证

- `npm test`：后端、分页、鉴权、头像来源与文字回退回归测试。
- `npm run test:webui:browser`：包含悬停/键盘/触屏操作、成员头像请求复用、可视化隐藏/恢复及刷新持久化测试。
- 浏览器测试使用合成联系人和图片，不发送真实微信或 Telegram 消息。
